# SensualXcape V2 · implementación y verificación

24/10/2026. Candidato preparado para GitHub Pages por autorización de Walker. Se mantiene la V1 pública existente. Publicación nueva pendiente: la conexión de GitHub disponible ha rechazado la escritura con HTTP 403. Esto no es una entrega desplegada ni una prueba física Android.

## Qué incorpora

- Las correcciones actuales de Studio, perfil, Cofre, guías, avisos y presentación se conservaron en un commit previo a los efectos (`1f56e72`).
- Noir como entrada principal; Rosa y Fucsia; imágenes del unicornio y la catedral, servicios compactos sin numeración y ayuda discreta con nombre accesible.
- Humo interactivo limitado a las ilustraciones de bienvenida, acceso profesional y escena del Cofre. Los controles ordinarios no lo generan.
- Superficies de cristal y reflejos discretos; respuesta breve al pulsar, al añadir un mensaje de muestra y al aceptar una solicitud ficticia. Estante opcional de tres accesos con profundidad, sin sustituir la lista de servicios.
- Cofre cerrado/abierto por toque, teclado o pulsación de 550 ms. Una sola escena y hasta cuatro objetos vinculados por ID a las mismas notas y archivos de la lista. Se pueden mover, recoger y recuperar. Esas acciones no eliminan ni cambian su contenido.
- Las asas de arrastre tienen al menos 44 px; el resto de la página permite desplazarse. Se conserva alta, búsqueda, filtros, edición, vista previa, descarga y borrado del Cofre.
- Preferencia «Luz y movimiento», Modo fácil y respeto de `prefers-reduced-motion`. Los efectos no cambian permisos ni acceso.

El render compatible utiliza CSS y una simulación fluida propia en Canvas 2D, con velocidad limitada, resolución acotada y pausa cuando no hace falta animar. La API experimental de captura HTML-in-Canvas nativa no se exige ni se anuncia como comprobada en Android. La imagen del cofre cerrado es una variante generada a partir de la ilustración existente, añadida como recurso local; no se carga desde un proveedor externo.

## Comprobación

Comprobaciones del candidato del 24/10:

- `npm test`: **248/248 pasan**, sin fallos ni pruebas omitidas. Incluye los contratos existentes y regresiones de Cofre, gestos, movimiento reducido y separación de versiones.
- `npm run build:pages`: correcto; cinco archivos V1 conservan sus SHA-256. `git diff --check`: sin errores.
- Revisión en el navegador a **320 × 746**, **390 × 844** y **1280 × 720** píxeles CSS. Sin desbordamiento horizontal en las vistas revisadas del Cofre, inicio y preferencias. Los tres temas, apagado de efectos y Modo fácil se comprobaron en pantalla.
- Creación de nota, arrastre con puntero, recogida con teclado, recuperación, lectura y descarga. El texto descargado coincide con el original. Tras tocar una tarjeta, la vista previa entra en pantalla.
- El enlace profundo privado tras recargar vuelve al acceso profesional; el perfil conserva sus distinciones entre notas privadas, presentación y elección de compartir. No se encontraron errores ni avisos en la consola de la revisión.

Las pruebas dirigidas incluyen eventos táctiles; los tamaños móviles del navegador no sustituyen un teléfono real. El enlace público sólo se dará por entregado tras verificar la publicación. Walker ha confirmado que lo probará en su Android cuando esté listo: arrastrar con el dedo, desplazamiento de la página, teclado, elección de archivos, apertura/cierre y rendimiento percibido.

La maqueta conserva sus límites: datos de prueba en memoria de la pestaña, sin cuentas autenticadas ni backend conectado. Los mensajes, comunidad y avisos son simulaciones. El Cofre no acredita cifrado ni persistencia: descargar antes de recargar conserva una copia. La referencia de Android es una web app adaptable; no se ha creado una APK ni un servicio de producción.

## Reproducir

```sh
npm ci
npm test
npm run build:pages
npm run preview:pages
```

Abrir V1 en `http://127.0.0.1:4349/SensualXcape/` y V2 en `http://127.0.0.1:4349/SensualXcape/v2/`. El servidor local no es un enlace accesible desde el teléfono por Internet.
